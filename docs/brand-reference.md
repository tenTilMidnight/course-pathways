# CMU color reference

Source: [Carnegie Mellon University Brand Standards — Colors](https://brand.cmu.edu/visual-identity/colors), checked 2026-10-18.

The user requests the Campus Palette as the likely source for future accents, and specifically selects **Skibo Red `#941120`** for the current prototype. The page uses this red with neutral surfaces and text. These preferences can be revised with the product design.

| Campus color | Official hexadecimal value |
| --- | --- |
| Machinery Hall Tan | `#BCB49E` |
| Kittanning Brick Beige | `#E4DAC4` |
| Hornbostel Teal | `#1F4C4C` |
| Palladian Green | `#719F94` |
| Weaver Blue | `#182C4B` |
| Skibo Red | `#941120` |

The official core red is Carnegie Red `#C41230`; it is distinct from Skibo Red. Official brand guidance treats the Campus Palette as secondary. This prototype follows the user's selected theme and does not claim university endorsement.

The six Campus Palette hex values are also captured in `src/config.js`. Keep university identity and theme choices in configuration when adding other campuses. Use an SVG/text identity for this product rather than an unlicensed or misleading university wordmark.
